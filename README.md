# Física Computacional y Métodos Numéricos en Python

Este repositorio contiene los scripts desarrollados en Python para el modelado de sistemas físicos, mecánica celeste, dinámica no lineal y métodos estocásticos en el Grado en Física de la Universidad Autónoma de Madrid (UAM)[cite: 2, 3, 5].

## Contenido del Repositorio

* **Mecánica y Dinámica de Sistemas:**
  * Integración numérica del movimiento pendular mediante esquemas de Euler y Euler-Cromer (`Péndulo_Euler.py`)[cite: 5].
  * Simulación de trayectorias y tiro parabólico con resistencia aerodinámica (`Proyectiles 2D.py`)[cite: 5].
  * Modelado de mecánica celeste y órbitas planetarias (`Planeta.py`)[cite: 5].

* **Sistemas Estocásticos y Física Estadística:**
  * Métodos de integración por Monte Carlo y simulación de paseos aleatorios (`Paseo Aleatorio.py`)[cite: 5].
  * Estudio de sistemas de espines, modelos térmicos y propagación de calor (`Tema 7 Espines.py`, `Calor_TPEC.py`)[cite: 5].
  * Potenciales intermoleculares y fuerzas de Lennard-Jones (`Fuerzas_LJ.py`)[cite: 5].

* **Caos y Tratamiento de Señal:**
  * Generación de mapas de Poincaré y análisis de doblado de periodo (`Poincare en el Doblado del Periodo.py`)[cite: 5].
  * Procesamiento de señal mediante Transformada Rápida de Fourier (`FFT Muestreo.py`)[cite: 5].

## Tecnologías Utilizadas
* Python 3 (NumPy, SciPy, Matplotlib)
* Entorno de desarrollo Visual Studio Code
